## Mover 插件完整通读（UE 5.9，D:\UnrealEngine\Engine\Plugins\Experimental\Mover）

核心结论：
- MoverComponent 不继承 NavMovementComponent（区别于 FloatingPawnMovement/CharacterMovement），原因是 Mover 采用"仿真与 AI 导航解耦"设计：UNavMoverComponent 是独立的 UActorComponent，实现 INavMovementInterface + IRVOAvoidanceInterface，作为 PathFollowing/AIMoveTo 的适配层；导航请求缓存在 NavMoverComponent（CachedNavMoveInputIntent/Velocity），由角色 ProduceInput 时经 ConsumeNavMovementData 消费写入 FCharacterDefaultInputs 的 MoveInput（Velocity 优先于 DirectionalIntent），再进仿真。
- NavWalkingMode 使用 NavMesh 而非碰撞移动：FindNavFloor/ProjectLocationFromNavMesh 投影、BehaviorOffNavMesh 策略、bSlideAlongNavMeshEdge，需 NavMoverComponent 提供 NavAgentProps/CollisionCylinder/PathFollowingAgent。
- 架构：UMoverComponent（UActorComponent + IMovementInterface）→ BackendLiaison（NetworkPrediction / Standalone / ChaosMover async）→ UKinematicActorSimulation（UMoverSimulation）→ UMovementModeStateMachine（FSM，substep 循环）→ UBaseMovementMode（GenerateMove 产出 FProposedMove，SimulationTick 执行）+ MovementMixer 混合。
- 数据模型：FMoverInputCmdContext / FMoverSyncState / FMoverAuxStateContext 均为 FMoverDataCollection（TSharedPtr<FMoverDataStructBase> 数组，按 UScriptStruct 类型唯一）；FCharacterDefaultInputs、FMoverDefaultSyncState（含 MovementBase/角速度）、FMoverAIInputs（RVO）为默认块。
- 扩展点：FLayeredMoveBase（struct，旧）/ ULayeredMoveLogic+FLayeredMoveInstance（BP 友好，logic 不复制、data 复制并网络化）、FMovementModifierBase（不产出移动，仅旁路修改）、FInstantMovementEffect（单 tick 直接改状态：Teleport/JumpImpulse/ApplyVelocity）、UBaseMovementModeTransition（Evaluate/Trigger，mode 内 + global 两级）。
- 模式清单：Walking（完整：floor check/step up/slide）、SimpleWalking（GenerateWalkMove 虚函数）、SmoothWalking（速度平滑）、SimpleSpringWalking、Falling（空气控制/终速）、Flying/SimpleFlying、Swimming、NavWalking + 各自 Async 版本。CharacterMoverComponent 默认注册 Walking/Falling/Flying，起始 Falling。
- 事件系统：FMoverSimulationEventData 子类（MovementModeChanged/Teleport/GamplayTagChange），sim 线程产生 → GT 分发（ProcessEvents/OnPostSimEventReceived），tag 事件 bReEmitOnResim。
- 待办确认：NPP 后端 resim 事件去重有 TODO（KinematicActorSimulation::RollbackToPriorState 注释）；UMoverComponent::ProduceInput 遍历 InputProducers 收集输入。

用户关注点解答：AIMoveTo 集成路径 = AIController(PathFollowing) → UNavMoverComponent(RequestDirectMove/RequestPathMove 缓存) → ProduceInput(ConsumeNavMovementData) → FCharacterDefaultInputs → 模式 GenerateMove；RVO 通过 IRVOAvoidanceInterface 接入 Detour Crowd，RVOVelocityDelta 走 FMoverAIInputs。
