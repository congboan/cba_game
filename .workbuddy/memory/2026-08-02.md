## 构建死锁最终解决（UBA 缓存损坏）

### 症状链
1. Stop hook 持续报 `[HARNESS] no successful build matching current source`
2. 根因：`Saved/` 目录被删 → 指纹缺失 → build_editor.py 重跑 → exit 6
3. UBA 缓存损坏：`C:\ProgramData\Epic\UnrealBuildAccelerator\cas\casdb` 仅 32 字节（空库）、`.isRunning`/`casdb.tmp` 写入 Access is denied
4. UBA 存储服务每次构建启动都加载坏库，动作执行异常：cl/link 秒挂（exit 1）、sarif 空、产生 0 字节 import lib

### 修复（两层）
1. **第一层（关键转折）**：`bAllowUBAExecutor=false` 写入项目级 `Saved/UnrealBuildTool/BuildConfiguration.xml`（正确位置，非 `Config/UnrealBuildTool/`）→ UBA executor 禁用（日志 `[NoUba]`），但 link 仍失败（引用 0 字节 lib）
2. **第二层（彻底解决）**：同文件追加 `UnrealBuildAccelerator` 段：
   ```xml
   <UnrealBuildAccelerator>
     <ForceNoCache>true</ForceNoCache>
     <AllowDetour>false</AllowDetour>
   </UnrealBuildAccelerator>
   ```
   → UBA 完全不读缓存、不 detour 进程 → 本地 cl/link 恢复正常
