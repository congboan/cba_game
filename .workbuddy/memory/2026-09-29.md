## PCG BiomeCore 诊断续：真正根因（同日第二轮）

**根因**：generator 图 `TPL_BiomeCore_Generator_Advanced` 内 `WorldRayHitQuery_0` 节点默认射线参数
`rayOrigin=(0,0,5000000)`、`rayDirection=(0,0,-1)`、`rayLength=5000000` → 射线 Z 下端恰好落在 `0`；
而场景地面 `Floor_0` 顶面在 `z=-0.5` → 射线打不到任何几何体 → `SurfaceSampler_0` 拿不到 surface
→ 0 点 → 整条链为空。

**实证（`SceneTools.trace_world`，只读）**：

- `(0,0,5000000) → (0,0,0)` → `null`（miss）
- `(-700,190,2000) → (-700,190,-2000)` → `2000.5`（命中点 `z=-0.5`，正是地板顶面）

**图内确认**：`Select_1`（Input A=`GetLandscapeData` / Input B=`WorldRayHitQuery` /
`bUseInputB=EnableWorldRayHitQuery`）→ `SurfaceSampler_0.Surface`，故 `enableWorldRayHitQuery`
确实是"表面来源"开关（false = 只用 Landscape，场景无 Landscape 就颗粒无收）。
`collisionChannel=ECC_WorldStatic` 而 Floor 是 `BlockAllDynamic`（全通道 Block）→ 碰撞通道不是问题。

**修复方向**：

1. 本质：`WorldRayHitQuery_0.RayLength` `5000000` → `10000000`（两种 rayOrigin 语义下均有效）。
   图模板位于引擎插件内 `D:/UnrealEngine/Engine/Plugins/Experimental/PCGBiomeCore/Content`，
   项目规则禁改引擎 → 需复制模板到项目、改副本、让 `DA_TreeGenerator.generatorGraph` 指向新图实例。
2. 快速验证：把 `Floor_0` 上移使顶面 `>= 0`。
3. 备选：`enableWorldRayHitQuery=false` + 场景加 Landscape。

**已排除**：volume.enabled/assets、actor tags(`PCG_BiomeActor`)、组件 tag(`PCG_LocalBiomeCore`)、
`DA_Forest`(biomeAssets.enabled=true/mesh=Cone/generator)、generator 解析链、LocalBiomeCache 链、
blending 链、地板碰撞配置。
